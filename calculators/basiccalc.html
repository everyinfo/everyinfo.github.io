🖩 일반 계산기

사칙연산, 메모리, 제곱·제곱근까지 — 윈도우 계산기처럼 익숙하게 쓸 수 있는 기본 계산기예요.

일반 계산기란

일반 계산기는 사칙연산과 백분율, 부호 변환 등 기본 계산을 수행하는 도구입니다.

계산 기준

이 계산기는 사무용 계산기처럼 입력한 순서대로 계산합니다. 2 + 3 × 4를 넣으면 곱셈을 먼저 하지 않고 2 + 3을 먼저 계산해 20이 나옵니다. 수학의 연산 순서대로 14를 얻으려면 3 × 4 = 로 12를 만든 뒤 2 + 12 = 로 계산하세요. 괄호 키는 없으므로 곱셈·나눗셈이 섞인 식은 결과를 확정해 가며 계산하는 편이 안전합니다.

계산기마다 답이 다른 이유

2 + 3 × 4를 넣었을 때, 공학용·소프트웨어 계산기는 연산 순서를 지켜 14가 나오지만 일반 사무용 계산기는 입력한 순서대로 처리해 20이 나옵니다. 사무용 계산기는 회계 장부 계산을 위해 만들어져 입력 순서를 따르는 게 자연스러웠던 겁니다. 헷갈리는 식은 곱셈·나눗셈을 먼저 계산해 = 로 결과를 확정한 뒤 더하고 빼면 안전합니다.

알아두면 좋은 이야기

  • 최초의 기계식 계산기는 1642년 파스칼이 19세에 만들었습니다. 프로그래밍 언어 파스칼이 그의 이름에서 왔습니다.
  • 0으로 나누면 오류가 뜨는 건 정의 자체가 불가능하기 때문입니다.
  • 0.1 + 0.2 = 0.30000000000000004 현상은 버그가 아니라 2진법에서 0.1이 무한소수라 생기는 근사 오차입니다.
  • M+ / MR / MC 키는 메모리 기능으로, 스마트폰 계산기에서 사라지면서 아는 사람이 줄었습니다.
  • 전자계산기 대중화 전엔 주판과 계산자가 그 자리를 대신했습니다.

메모리 키로 소계 합치기

예: 장바구니 소계 3,200 + 4,500 + 1,800원

  • 1단계 3200을 넣고 MS — 메모리에 첫 소계가 저장되고 화면에 M 표시가 켜집니다.
  • 2단계 C로 지운 뒤 4500을 넣고 M+, 다시 C로 지운 뒤 1800도 M+를 누릅니다.
  • 3단계 MR을 누르면 합계 9,500이 나옵니다.

M+·M−는 지금 화면에 보이는 값을 메모리에 더하거나 뺍니다. 그래서 2 + 3 같은 식을 넣는 중이라면 = 를 먼저 눌러 결과를 확정한 뒤 M+를 눌러야 합니다. 메모리는 MC로 지울 때까지 남아 있으므로, 다음 계산에서 MR을 눌렀을 때 엉뚱한 값이 나오면 M 표시를 먼저 확인하세요.

  • MS 저장(덮어쓰기), M+ 더하기, M− 빼기, MR 불러오기, MC 지우기입니다.
  • M+를 두 번 누르면 같은 값이 두 번 더해집니다. 누른 뒤 화면 값을 확인하는 습관이 안전합니다.
  • 여러 품목을 합산할 때는 소계 계산 → = → M+ 순서로 진행하세요.

키보드로 계산하기

계산기 영역을 한 번 누르면 키보드로 바로 입력할 수 있습니다. 숫자 키와 함께 아래 키가 동작합니다.

  • Enter 또는 = — 계산 실행. 결과가 나온 뒤 한 번 더 누르면 직전 연산이 반복됩니다(2+3= → 5, = → 8).
  • Backspace — 마지막 숫자 한 자리 지우기(⌫).
  • Esc — 전체 초기화(C). 방금 넣은 값만 지우려면 화면의 CE를 누릅니다.
  • + - * / — 키보드 기호를 그대로 쓰면 ×와 ÷로 바뀌어 들어가고, % 키도 그대로 동작합니다.

%와 √를 쓸 때 주의할 점

이 계산기의 %는 앞에 연산자가 있으면 그 값의 퍼센트로 계산합니다. 200 + 10% 는 200의 10%(=20)를 더해 220이 됩니다. 연산자 없이 %만 누르면 100으로 나눈 값이 되어 200% → 2가 됩니다.

  • %는 기종마다 다릅니다. 일부 사무용 계산기는 200 + 10%를 200.1로 처리합니다. 영수증과 1원 차이가 나면 이 차이일 수 있습니다.
  • √는 음수에서 오류가 납니다. 실수 범위에 답이 없기 때문이며, 제곱근은 0 이상의 값만 받습니다.
  • x²는 현재 값에 바로 적용됩니다. 3 + 4를 넣은 뒤 x²를 누르면 4만 제곱해 19가 되니, 합계를 제곱하려면 = 로 결과를 확정한 뒤 누르세요.
  • 1/x 에서 0은 오류입니다. 0으로 나누는 계산은 정의되지 않습니다.
  • 소수 계산은 표시 자릿수까지만 보입니다. 10 ÷ 3 × 3이 화면에 10으로 돌아와도 내부 값은 미세하게 다를 수 있습니다.

생활 계산 예

예 1: 47,500원을 3명이 나눠 내기

  • 47,500 ÷ 3 = 15,833.33… — 한 명이 15,830원씩 내고 남는 10원을 한 명이 더 내면 맞습니다.

예 2: 부가세 포함 33,000원의 공급가액

  • 33,000 ÷ 1.1 = 30,000원 (부가세 3,000원)
  • 10%를 그냥 빼면 29,700원이 되어 틀립니다.

부가세처럼 이미 붙은 비율을 거꾸로 빼는 계산은 나눗셈으로 해야 합니다. 자세한 계산은 부가세 계산기에서 확인할 수 있습니다.

자주 묻는 질문

Q. 2 + 3 × 4는 14인가요, 20인가요?

수학적으로는 14입니다. 일부 사무용 계산기는 입력 순서대로 처리해 20이 나옵니다.

Q. 0으로 나누면 왜 오류인가요?

어떤 수를 0에 곱해도 원래 값이 나오지 않아, 답이 정의되지 않기 때문입니다.

Q. % 키는 어떻게 작동하나요?

기종마다 다릅니다. 200+10%를 220으로 계산하는 것도, 200.1로 계산하는 것도 있습니다.

Q. 메모리 M+는 언제 누르나요?

화면에 보이는 값을 메모리에 더합니다. 2+3을 계산 중이라면 = 를 먼저 눌러 5를 확정한 뒤 M+를 눌러야 5가 더해집니다.

Q. 화면에 M 표시가 떠 있는데 어떻게 지우나요?

메모리에 값이 남아 있다는 뜻입니다. MC를 누르면 지워지고 M 표시도 사라집니다. MS로 새 값을 덮어써도 됩니다.

Q. 키보드로도 계산할 수 있나요?

계산기 영역을 한 번 누른 뒤 숫자와 연산자 키를 쓰면 됩니다. Enter는 =, Backspace는 한 자리 지우기, Esc는 전체 초기화입니다.

Q. 2 + 3 × 4가 왜 20이 나오나요?

이 계산기는 사무용 계산기처럼 입력한 순서대로 계산하기 때문입니다. 곱셈을 먼저 하려면 3 × 4 = 로 12를 만든 뒤 2 + 12 = 로 계산하세요.

Q. = 를 두 번 누르면 왜 값이 또 바뀌나요?

직전 연산이 반복되기 때문입니다. 2+3= 다음에 = 를 한 번 더 누르면 5+3=8이 됩니다. 반복을 끝내려면 C를 누르세요.
