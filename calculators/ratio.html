⚖️ 비율 계산기

A : B = C : D 비례식과 A/B = C 관계식, 두 가지 비율 계산을 한 곳에서 해요.

비율·비례식 계산기란

비율 계산기는 A:B = C:X 형태의 비례식에서 미지수를 구하거나, 두 값의 비율을 간단히 정리하는 도구입니다. 레시피 양 조절, 도면 축척, 혼합 비율 계산에 사용합니다.

계산 기준

A : B = C : X → X = B × C ÷ A
비례식의 기본 성질인 내항의 곱 = 외항의 곱을 이용합니다.

알아두면 좋은 이야기

  • 도면의 축척 1:100은 "도면에서 1cm가 실제 100cm"라는 뜻입니다. 분모가 클수록 축소된 그림입니다.
  • 황금비(약 1:1.618)는 자연과 예술에서 반복적으로 등장한다고 알려져 있지만, 실제로는 후대에 끼워 맞춘 사례가 많다는 반론이 상당합니다.
  • A4 용지의 비율(1:√2)은 훨씬 실용적인 설계입니다. 반으로 접으면 정확히 같은 비율이 되기 때문에 A3→A4→A5로 계속 나눠도 형태가 그대로입니다.
  • 시멘트 배합비 1:2:4처럼, 건설·화학 현장은 비율로 소통합니다. 총량이 바뀌어도 비율만 지키면 성질이 유지됩니다.
  • 지도 축척에서 대축척·소축척은 직관과 반대입니다. 1:5,000이 대축척(자세함), 1:500,000이 소축척(넓은 범위)입니다.

자주 묻는 질문

Q. 비와 비율은 다른 건가요?

비는 두 양의 관계(3:2), 비율은 기준량에 대한 비교량의 크기(3/2 또는 150%)입니다.

Q. 축척 1:100과 1:50 중 어느 쪽이 큰 도면인가요?

1:50입니다. 같은 대상을 더 크게 그린 것이라 세부가 더 자세합니다.

Q. 레시피를 1.5배로 늘리려면요?

모든 재료에 1.5를 곱하면 됩니다. 다만 소금·베이킹파우더 같은 팽창제는 비례보다 조금 적게 넣는 것이 안전합니다.
