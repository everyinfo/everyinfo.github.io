🔢 Basic Calculator

A familiar calculator with memory (MC/MR/M+/M-) and square/square root — just like the classic Windows calculator.

What is a Basic Calculator?

The basic calculator handles arithmetic, percentages, and sign changes for everyday calculations.

How it's calculated

This calculator works like an office calculator: it processes entries in the order you type them. Enter 2 + 3 × 4 and it adds first, giving 20 rather than 14. To follow standard order of operations, settle the multiplication first (3 × 4 = gives 12) and then add (2 + 12 =). There is no parenthesis key, so with mixed operators it is safer to confirm one step at a time.

Why different calculators give different answers

Enter 2 + 3 × 4 and a scientific or software calculator gives 14 (following order of operations), while a basic office calculator often gives 20 (processing left to right as entered). Basic calculators were originally built for bookkeeping, where entries are added sequentially, so processing in entry order made practical sense. When in doubt, settle the multiplication or division first (=) and then add or subtract.

Good to know

  • The first mechanical calculator was built by Blaise Pascal in 1642, at age 19, to help his father with tax accounting.
  • Dividing by zero produces an error not because the answer is infinity, but because no number multiplied by zero can produce the original value — the operation is fundamentally undefined.
  • The famous 0.1 + 0.2 = 0.30000000000000004 quirk isn't a bug — it's a rounding artifact from how binary systems represent 0.1 as a repeating fraction.
  • The M+/MR/MC memory keys let you accumulate intermediate results across multiple calculations — a feature many people have forgotten now that most calculating happens on phones.
  • Before electronic calculators became common, the abacus and slide rule filled the same role.

Adding up subtotals with the memory keys

Example: grocery subtotals of 3,200 + 4,500 + 1,800

  • Step 1 Type 3200 and press MS. The first subtotal goes into memory and the M flag lights up.
  • Step 2 Press C, type 4500 and press M+, then C again, type 1800 and press M+.
  • Step 3 Press MR to recall the total: 9,500.

M+ and M− add or subtract the value currently on screen. So if you are in the middle of an expression like 2 + 3, press = first to settle the result, then M+. Memory stays until you clear it with MC, so if MR brings back an unexpected number, check the M flag.

  • MS stores (overwrites), M+ adds, M− subtracts, MR recalls, MC clears.
  • Pressing M+ twice adds the same value twice. Glance at the screen after each press.
  • For a list of items, work in the order calculate the subtotal → = → M+.

Using the keyboard

Click once inside the calculator and you can type instead of tapping. These keys work in addition to the digits.

  • Enter or = evaluates. Press it again and the last operation repeats (2+3= gives 5, then = gives 8).
  • Backspace deletes the last digit (⌫).
  • Esc clears everything (C). To clear only the number you just typed, use CE on screen.
  • + - * / are accepted as typed and mapped to × and ÷, and the % key works too.

Watching out with % and √

When an operator is pending, % applies to the value before it: 200 + 10% adds 10% of 200, giving 220. Pressed with no pending operator, % simply divides by 100, so 200% becomes 2.

  • % differs by model. Some office calculators treat 200 + 10% as 200.1. A one-won gap against a receipt can come from exactly this.
  • √ of a negative number is an error because no real square root exists.
  • x² applies to the current value immediately. After typing 3 + 4, x² squares only the 4 and returns 19. Press = first to square a total.
  • 1/x with 0 is an error: division by zero is undefined.
  • Decimals are shown to the displayed precision only, so 10 ÷ 3 × 3 can read as 10 while the underlying value differs slightly.

Everyday examples

Example 1: splitting 47,500 three ways

  • 47,500 ÷ 3 = 15,833.33… — three people at 15,830 leaves 10 to add on one share.

Example 2: the supply price inside 33,000 including VAT

  • 33,000 ÷ 1.1 = 30,000 (VAT 3,000)
  • Subtracting 10% instead gives 29,700, which is wrong.

Removing a percentage that is already included always means dividing, not subtracting. The VAT calculator does this step for you.

Frequently asked questions

Q. Is 2 + 3 × 4 equal to 14 or 20?

Mathematically, 14. Some basic office calculators process entries left to right instead, giving 20.

Q. Why does dividing by zero cause an error?

No value multiplied by zero produces the original number, so the result is mathematically undefined.

Q. How does the % key work?

It varies by model. Some calculators compute 200 + 10% as 220, others as 200.1.

Q. When do I press M+?

It adds the value on screen to memory. In the middle of 2+3, press = first so 5 is settled, then M+.

Q. There is an M on screen — how do I clear it?

It means memory holds a value. Press MC to clear it and the M disappears; MS overwriting the memory also works.

Q. Can I use the keyboard?

Yes. Click inside the calculator, then type: Enter is =, Backspace deletes a digit and Esc clears everything.

Q. Why does 2 + 3 × 4 give 20?

This calculator evaluates entries in the order you type them, like an office calculator. To multiply first, do 3 × 4 = (12) and then 2 + 12 =.

Q. Why does pressing = again change the answer?

It repeats the previous operation: after 2+3= gives 5, = adds 3 again for 8. Press C to stop the repetition.
